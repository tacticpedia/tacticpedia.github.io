개인정보처리방침

시행일: 2026년 11월 12일

1. 누가, 무엇에 쓰나요

Tacticpedia Uploader(이하 '이 도구')는 유튜브 채널 전술백과의 운영자가 본인 채널에 영상을 올리고 첫 댓글을 다는 데만 쓰는 개인용 도구입니다. 운영자 외의 사용자는 없습니다.

2. 접근하는 Google 사용자 데이터

  • youtube.upload: 운영자 채널에 영상을 업로드하고 썸네일을 지정합니다.
  • youtube.force-ssl: 운영자가 올린 영상에 첫 댓글을 달고, 업로드한 영상의 공개 상태를 확인하며, 연결된 채널 이름을 확인합니다.

다른 사람의 채널, 영상, 댓글, 구독 정보 등은 읽거나 수집하지 않습니다.

3. 저장과 보관

로그인 후 발급되는 인증 토큰은 운영자 본인의 컴퓨터에만 저장됩니다. 외부 서버에 저장하거나 전송하지 않습니다. 업로드 결과(영상 ID, 링크)만 운영자의 작업 폴더에 기록합니다.

4. 공유

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않습니다. 광고·분석·AI 모델 학습에도 사용하지 않습니다.

5. 권한 철회

Google 계정의 타사 연결 페이지에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

6. Google API 서비스 사용자 데이터 정책

이 도구가 Google API로 받은 정보를 사용하는 방식은 Google API Services User Data Policy와 그 제한적 사용(Limited Use) 요건을 따릅니다.

Privacy Policy

Effective date: November 12, 2026

Who uses it. Tacticpedia Uploader is a private tool used solely by the owner of the Tacticpedia YouTube channel to upload videos to that channel and post a first comment on them. There are no other users.

Google user data accessed. youtube.upload to upload videos and set thumbnails on the owner's channel; youtube.force-ssl to post a comment on the owner's own videos, check the privacy status of uploaded videos, and read the connected channel's name. No data about other channels, videos, comments or subscriptions is read or collected.

Storage. OAuth tokens are stored only on the owner's own computer and are never sent to or stored on any external server. Only upload results (video IDs and links) are recorded in the owner's working folder.

Sharing. Google user data is not sold or shared with third parties and is not used for advertising, analytics, or training AI models.

Revoking access. Access can be revoked at any time from the third-party connections page of the Google Account.

Google API Services User Data Policy. Tacticpedia Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
